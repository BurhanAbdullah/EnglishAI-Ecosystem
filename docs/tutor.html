Adaptive tutoring agents

Every learner gets a tutor that learns how to teach them.

EnglishAI is designed to evolve from a generic language assistant into an adaptive tutoring system: each learner has a persistent learning context, goals, strengths, recurring errors, practice history and feedback loop.

Tutor model
01

Learner profile

Capture proficiency, target skills, goals, first language, course context and preferences explicitly rather than inferring everything from a prompt.

02

Adaptive diagnosis

Use attempts, errors, assessment signals and interaction history to estimate what the learner needs next.

03

Personal lesson policy

Select explanation depth, examples, difficulty, pacing and practice type according to the learner context.

04

Specialist agents

Coordinate grammar, vocabulary, reading, writing and assessment capabilities rather than forcing one agent to do everything.

05

Feedback + retry

Turn each attempt into actionable feedback, then generate a targeted retry instead of simply giving the answer.

06

Longitudinal learning

Track progress and recurring patterns so the tutor can revisit weak areas, increase challenge and avoid unnecessary repetition.

Agent orchestration

One learner context. A coordinated team of specialists.

Tutor Agent

Plans the session

Understands the learner goal, selects a learning objective and coordinates the specialist capabilities.

Diagnostic Agent

Finds the gap

Analyses learner responses and identifies skill, error and confidence signals.

Practice Agent

Creates the next task

Generates constrained exercises matched to current ability and the target skill.

Evidence Agent

Grounds explanations

Retrieves authorised learning resources and attaches provenance when evidence is required.

Assessment Agent

Measures progress

Validates answers and produces structured signals rather than unsupported mastery claims.

Coach Agent

Adapts the strategy

Uses longitudinal signals to decide whether to reteach, practise, increase difficulty or change approach.

The adaptive loop
DiagnoseWhat does this learner know now?
TeachWhat explanation will help?
PractiseWhat task targets the gap?
AssessDid the learner improve?
Important: adaptive tutoring is a research and implementation direction. The repository should only claim persistent learner intelligence, mastery estimation or autonomous agent behaviour once those components are implemented and evaluated.
