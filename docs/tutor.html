Tutor model
01

Learner profile

Capture level, first language, target skills and goals explicitly.

02

Adaptive diagnosis

Use responses and errors to identify what the learner needs next.

03

Personal learning path

Select explanation, examples, difficulty and practice around the learner.

04

Specialist capabilities

Coordinate grammar, vocabulary, reading, writing and assessment services.

05

Feedback + retry

Turn each attempt into useful feedback and a targeted next task.

06

Longitudinal progress

Track learning signals so the tutor can revisit gaps and raise challenge.
