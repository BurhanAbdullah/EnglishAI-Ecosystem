SYSTEM FLOW

Every request closes the learning loop.

01 · CONTEXT

Establish state

Receive the learner request, load profile and determine intent, goal and target skill.

02 · EVIDENCE

Prepare knowledge

Retrieve authorised resources when evidence is required and preserve provenance metadata.

03 · AGENTS

Select a specialist

Route the task to a bounded tutor, diagnostic, practice, assessment, coach or evidence role.

04 · VALIDATE

Check the contract

Validate structured inputs and outputs before a capability is executed.

05 · EXECUTE

Run a capability

Apply policy and invoke a focused service with explicit boundaries and predictable results.

06 · ADAPT

Update learning state

Turn performance into signals that shape feedback, mastery and the next activity.
