REQUEST LIFECYCLE

From learner request to the next practice task.

01–04

Establish context

Receive the request, establish identity, load learner context, then determine intent and target skill.

05–08

Prepare execution

Determine retrieval needs, retrieve authorised evidence, select a capability and validate its input.

09–12

Execute safely

Apply policy, execute the bounded capability, return structured results and generate learner-facing output.

13–16

Close the loop

Present the activity, record permitted signals, update learning state and select subsequent practice.

RAG

Authorised retrieval

Learning resources can be cleaned, chunked, metadata-enriched and filtered before evidence reaches the tutor.

MCP

Capability boundaries

Specialist operations remain behind explicit schemas, permissions, safety constraints and provenance requirements.
