ABOUT THE PROJECT

Designed to teach the learner in front of it.

Modern English combines learner context, specialist capabilities, assessment and adaptive feedback into a continuous 1-to-1 learning loop.

Start learning →Explore architecture
THE LOOP

Profile → Diagnose → Teach → Practise → Evaluate → Adapt

Each interaction can contribute evidence about the learner's current needs, making the next activity more targeted.

01 · CONTEXT

Learner model

Goals, proficiency, target skill and recent attempts provide structured tutoring context.

02 · SPECIALISTS

MCP capabilities

Grammar, vocabulary, reading, writing and assessment services provide focused operations behind the tutor.

03 · ADAPTATION

Evidence-driven next step

Performance signals can drive remediation, review, practice or increased challenge.
