About the project

EnglishAI is designed to teach the learner in front of it.

Instead of treating every learner as a fixed-level quiz taker, the platform builds a learner context, measures responses, identifies recurring weaknesses and adapts what comes next.

1-to-1 tutoring loop

Profile → diagnose → teach → practise → evaluate → update mastery → adapt. Each turn can use the learner's current goal, skill and recent attempts.

Specialist MCPs

Grammar, vocabulary, reading, writing, assessment and evidence services are separated so the tutor can route work to the appropriate capability.

Built for growth

The web client is a lightweight learner surface while the gateway provides the orchestration boundary needed for persistent, scalable tutoring services.

How it works

From first visit to an adaptive lesson

01 · Secure sign-in

Sign in with the configured identity provider so the learner does not repeatedly re-enter profile details.

02 · Learner model

Goals, proficiency, target skill and observed attempts become structured tutoring context.

03 · Pedagogical decision

The tutor selects whether to teach, practise, remediate, review or challenge based on evidence from recent performance.
