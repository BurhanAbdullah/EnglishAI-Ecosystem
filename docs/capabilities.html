CAPABILITIES · AGENTS

Specialists for every part of the learning workflow.

Modern English uses focused agents and bounded capabilities rather than one monolithic tutor. Each responsibility can be tested, replaced and improved independently.

Meet the tutor →
T

Tutor Agent

Coordinates intent, learner context and the next action across the learning loop.

D

Diagnostic Agent

Interprets answers, detects gaps and identifies skills that need attention.

P

Practice Agent

Targets practice to current proficiency and adjusts challenge from performance.

A

Assessment Agent

Validates responses, tags skills and emits structured learning signals.

C

Coach Agent

Shapes explanations, feedback, retries and progression guidance.

E

Evidence Agent

Handles retrieval and provenance when learner-facing answers require evidence.

CORE CAPABILITIES

Skills stay focused. Context stays shared.

01 · GRAMMAR

Diagnose, explain, practise

Identify grammatical issues, explain rules and create targeted practice.

02 · VOCABULARY

Learn words in context

Support definitions, examples, collocations, word families and recall.

03 · READING

Read with evidence

Support comprehension, evidence extraction and readability-aware activities.

04 · WRITING

Diagnose before rewriting

Surface grammar, lexical and organisation issues with revision guidance.

05 · ASSESSMENT

Measure learning signals

Validate answers, tag skills and produce structured signals.

06 · CITATION

Keep provenance visible

Resolve sources and validate evidence pathways for grounded responses.
