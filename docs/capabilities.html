CAPABILITIES · SPECIALIST AGENTS

Not one giant tutor.
A coordinated team.

Each specialist has a defined responsibility. The tutor coordinates the experience while diagnostic, practice, assessment, coaching and evidence services contribute focused signals.

Try the tutor →See the architecture
THE SIX SPECIALISTS

Clear roles. Shared learner context.

T

Tutor Agent

Coordinates learner intent, current state and the next action across the learning loop.

Orchestration · sequencing
D

Diagnostic Agent

Interprets performance, detects gaps and identifies the skills that need targeted attention.

Diagnosis · gap detection
P

Practice Agent

Selects activities and adjusts challenge according to current proficiency and observed performance.

Practice · adaptation
A

Assessment Agent

Validates responses, tags skills and turns attempts into structured learning signals.

Validation · measurement
C

Coach Agent

Shapes explanations, feedback, retries and progression guidance around the learner's needs.

Feedback · progression
E

Evidence Agent

Handles retrieval and provenance when learner-facing answers require grounded evidence.

Retrieval · provenance
LEARNING CAPABILITIES

Skills stay focused. The learner stays central.

01 · GRAMMAR

Diagnose → explain → practise

Identify grammatical issues, explain relevant rules and create targeted practice.

02 · VOCABULARY

Words in context

Support definitions, examples, collocations, word families and recall.

03 · READING

Comprehension with evidence

Support passage understanding, evidence extraction and readability-aware activities.

04 · WRITING

Diagnose before rewriting

Surface grammar, lexical and organisation issues while preserving the learner's voice.

05 · SPEAKING

Practice communication

Structure speaking practice around goals, prompts, feedback and progression signals.

06 · LISTENING

Build comprehension

Target listening activities to proficiency and use performance to guide subsequent practice.
