The core idea

Learning is a loop.
Not a lesson list.

The system keeps a living learner state. It uses context and demonstrated performance to decide what should happen next, then feeds the result back into the model.

How it responds

Every answer changes the picture.

Instead of treating a response as the end of a question, Modern English treats it as evidence about the learner.

01
Profile the learnerLevel, goals, target skill and context.
02
Diagnose the gapFind what is strong, uncertain or ready for challenge.
03
Choose the next actionPractice, teach, review or increase difficulty.
04
Learn from the attemptUpdate the learner state and continue the loop.
The agent layer

Six specialists.
One tutor.

The learner does not need to orchestrate agents. Specialist responsibilities stay behind one coherent experience, making the system easier to test, reason about and extend.

01 · COORDINATION
T

Tutor Agent

Coordinates learner context, intent and the next learning action. It is the experience layer that turns specialist decisions into one coherent path.

Context → learner stateIntent → learning actionDecision → next step
02 · DIAGNOSIS
D

Diagnostic

Identifies skill gaps and interprets performance signals.

03 · PRACTICE
P

Practice

Creates targeted activities at an appropriate challenge.

04 · ASSESSMENT
A

Assessment

Validates responses and turns attempts into evidence.

05 · COACHING
C

Coach

Shapes explanations, feedback and retries.

06 · EVIDENCE

Keeps retrieval, sources and provenance explicit when evidence matters.
