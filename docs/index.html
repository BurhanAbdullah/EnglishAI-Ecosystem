THE AGENT LAYER

Six specialists.
One tutor experience.

Focused responsibilities make the system easier to reason about, test and improve — while the learner sees one coherent tutor.

T

Tutor Agent

Coordinates intent, learner context and the next learning action.

D

Diagnostic Agent

Identifies skill gaps and interprets performance signals.

P

Practice Agent

Creates targeted activities at an appropriate challenge level.

A

Assessment Agent

Validates responses and turns attempts into structured evidence.

C

Coach Agent

Shapes explanations, feedback, retries and learning momentum.

E

Evidence Agent

Keeps retrieval, sources and provenance explicit when evidence matters.
