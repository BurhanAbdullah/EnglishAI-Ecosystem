Agent layer

Specialist agents. One tutor experience.

Each agent owns a focused responsibility. The tutor coordinates them through explicit, testable capability boundaries.

T

Tutor Agent

Coordinates learner intent, context and the next learning action.

D

Diagnostic Agent

Identifies skill gaps and interprets learner performance signals.

P

Practice Agent

Creates targeted activities at an appropriate difficulty.

A

Assessment Agent

Validates answers and produces structured learning evidence.

C

Coach Agent

Shapes explanations, feedback, retries and motivation.

E

Evidence Agent

Keeps retrieval, sources and provenance explicit when evidence is needed.
