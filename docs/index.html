The learning loop

One learner.
One evolving path.

No fixed sequence pretending every learner is the same. Profile, performance and feedback continuously become evidence for the next learning action.

01

Profile

Start with level, goals, target skills and learner context.

02

Diagnose

Find strengths and gaps through focused, interpretable evidence.

03

Practise

Deliver activities at a challenge level informed by demonstrated skill.

04

Adapt

Use every response to shape difficulty, feedback and the next action.

Inside the platform

A tutor experience.
Not a black box.

Specialist responsibilities keep the learning system understandable, testable and extensible while the learner sees one coherent tutor.

Agent layer

Six specialists. One coordinated experience.

The system separates diagnosis, practice, assessment, coaching and evidence responsibilities so each part can be evaluated independently.

Tutor AgentCoordinates the next learning action.
Diagnostic AgentInterprets learner gaps.
Practice AgentTargets the right challenge.
Assessment AgentTurns attempts into evidence.
Coach AgentShapes feedback and retries.
Evidence AgentKeeps provenance explicit.
