Quick start

Run the development foundation.

git clone https://github.com/BurhanAbdullah/EnglishAI-Ecosystem.git
cd EnglishAI-Ecosystem
npm install
npm run typecheck
npm test
npm run test:mcp
Current repository status is prototype / active development. The intended orchestrator, production RAG deployment, persistence, production transport, security controls and educational evaluation should be treated as implementation targets unless explicitly present and tested in the repository.
