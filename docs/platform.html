PLATFORM

A learning stack designed to adapt continuously.

Modern English separates learner context, evidence, inference, specialist agents, executable capabilities and learning state so every layer can be tested and improved independently.

Try the tutor →Explore architecture
01 · CONTEXT

Learner model

Goals, proficiency, target skill and performance signals establish the current learning state.

02 · EVIDENCE

Retrieval + provenance

Relevant authorised resources can be assembled with explicit source metadata.

03 · AGENTS

Specialist reasoning

Tutor, diagnostic, practice, assessment, coach and evidence responsibilities stay bounded.

04 · CAPABILITY

MCP services

Focused tools expose explicit inputs, outputs, policies and validation boundaries.

05 · FEEDBACK

Practice loop

Answers become signals that shape explanation, difficulty and the next activity.

06 · STATE

Continuous adaptation

Learning state is updated after attempts so the experience can evolve over time.
