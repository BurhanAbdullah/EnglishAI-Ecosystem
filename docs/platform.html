Platform

A modular learning stack built around evidence and capability boundaries.

EnglishAI separates knowledge, inference, executable capabilities and learning state so each layer can be tested, replaced and governed independently.

01 · Knowledge

Approved resources

English-learning resources and metadata become structured inputs for retrieval and provenance.

02 · Retrieval

Evidence package

Relevant authorised evidence is assembled before learner-facing generation when retrieval is required.

03 · Inference

Local model/runtime

Language generation operates as one component in a wider learning workflow.

04 · Capability

MCP services

Specialised tools expose bounded operations through explicit inputs, outputs and policies.

05 · State

Learner context

Proficiency, target skill, goals and course context are carried explicitly through the system.

06 · Learning

Practice + feedback

Attempts generate diagnostic and assessment signals for subsequent practice and improvement.
