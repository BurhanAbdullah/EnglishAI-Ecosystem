THE PLATFORM

One learning system.
Built to adapt.

Modern English connects learner context, evidence, specialist agents, executable capabilities and learning state into a testable learning loop. The interface stays simple while the underlying system remains modular.

Create your account →Open tutor
THE STACK

Six layers. One continuous loop.

01 · CONTEXT

Learner model

Goals, proficiency, target skill and recent performance establish the current learning state.

02 · EVIDENCE

Grounded resources

Authorised content and source metadata support explanations, activities and auditable outputs.

03 · REASONING

Specialist agents

Tutor, diagnostic, practice, assessment, coach and evidence roles keep responsibilities explicit.

04 · CAPABILITY

Focused services

MCP-style services expose narrow operations with defined inputs, outputs and validation boundaries.

05 · FEEDBACK

Practice signals

Responses, accuracy and observed performance become structured signals for the next activity.

06 · STATE

Adaptation

Learning state is updated after attempts so difficulty, explanation and practice can evolve.

WHY THIS STRUCTURE

Simple for learners.
Inspectable for researchers.

The platform separates concerns so individual components can be tested, replaced and evaluated without rebuilding the entire experience.
