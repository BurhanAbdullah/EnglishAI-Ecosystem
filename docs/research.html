Research program

Study whether grounded, modular AI changes the learning system.

The repository frames EnglishAI as a research infrastructure as much as a software framework: hypotheses stay distinct from deployed functionality, and evaluation spans reliability and educational outcomes.

RQ01

Evidence grounding

How does retrieval quality and provenance affect reliability, unsupported-answer rate and learner trust?

RQ02

Specialised capabilities

Do domain-specific MCP services outperform a generic interaction pattern on diagnosis, practice and validation?

RQ03

Learner context

How does explicit proficiency, target skill and learning-goal conditioning affect activity relevance?

RQ04

Iterative feedback

Does the explain → practise → attempt → feedback → retry loop improve error reduction and retention?

RQ05

Local deployment

What trade-offs emerge across privacy, latency, infrastructure cost, model quality and observability?

RQ06

Teacher governance

How should teachers inspect evidence, constrain capabilities and interpret learning signals?
