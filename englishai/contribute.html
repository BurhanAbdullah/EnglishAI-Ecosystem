Open contribution

Two ways to contribute.

You can contribute directly to the public GitHub repository without joining the team, or apply to join the collaboration group for coordinated work with the project leads.

Path A · Open source

Contribute directly to GitHub.

Fork the repository, improve code or documentation, add an MCP service, improve learning resources, report issues, propose features or submit a pull request.

Open repository →Issues
Path B · Collaboration group

Join the EnglishAI team.

Apply when you want to work as part of an ongoing stream. Tell us your background, preferred role, contribution area, ideas and suggestions. A project lead reviews applications before group membership is approved.
