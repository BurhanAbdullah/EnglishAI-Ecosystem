The ecosystem

More than a chatbot.

The platform is organised around a continuous learning loop: Ask → Explain → Practise → Attempt → Feedback → Retry → Improve.

01 · LEARN

English learning tools

Grammar, vocabulary, reading, writing and assessment experiences designed around proficiency and practice.

02 · GROUND

Knowledge + RAG

Authorised resources are structured, retrieved and presented as evidence rather than relying only on model memory.

03 · EXTEND

MCP capabilities

Specialist learning functions are exposed through explicit, typed and permission-aware interfaces.

04 · CONTROL

Configurable local LLM

Local means controllable deployment. The operator can choose the model, runtime, hardware, access policy and integrations.

05 · MEASURE

Assessment + progress

Learning activities generate useful signals for mastery, feedback and future practice.

06 · GOVERN

Provenance + safety

Source lineage, permissions, validation, auditability and controlled tool execution are part of the design.

Local LLM, correctly understood

Local is a deployment choice.

EnglishAI does not define “local” as institution-only. A local model can be operated by an individual, research group, school, university, organisation or another deployment owner. The value is greater control over the model and its surrounding infrastructure.
