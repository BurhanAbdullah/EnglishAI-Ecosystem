Building the next generation of English learning.

EnglishAI-Ecosystem is a modular platform for teaching English as a second or additional language. We are bringing learning resources, RAG, configurable local-model inference, MCP capabilities, assessment and learner feedback into one extensible system.

What we are building

A complete language-learning ecosystem.

01 · KNOWLEDGE

English resources + RAG

Resources are organised, indexed and retrieved with metadata and provenance so learning responses can be grounded in relevant evidence.

02 · INFERENCE

Configurable local LLM

Local describes a controllable deployment model. The operator can choose the model, runtime, hardware, access policy and integrations.

03 · CAPABILITIES

MCP learning services

Grammar, vocabulary, reading, writing, assessment, citation and content capabilities are exposed through explicit interfaces.

04 · LEARNING STATE

Learner context + mastery

Goals, proficiency, practice history, feedback and mastery signals can shape the next activity.

05 · TEACHING

Student + teacher experience

A shared interface supports learner practice while giving teachers meaningful visibility and control.

06 · TRUST

Governance + provenance

Permissions, validation, versioning, evidence lineage and auditability are designed into the system boundary.

RUNTIME FLOW

Question → context → evidence → inference → tool → practice → feedback

The learner experience stays connected to the technical stack so interactions can support a meaningful learning cycle.

Local-first inference

Control the deployment.

Local does not mean institution-only. A local model can be operated by an individual, research group, school, university, organisation or another deployment owner. The key idea is control over the model environment and surrounding resources.

MCP GOVERNANCE

Explicit capabilities, explicit control.

Tools can be typed, validated, versioned, permission-aware and auditable. This makes the ecosystem extensible without turning the model into an unrestricted application controller.
