From learner intent to adaptive feedback.

01 · CAPTURE

Intent + learner context

The interface receives a learning question, task or goal alongside available learner context.

02 · RETRIEVE

Ground the response

RAG retrieves relevant resources and evidence using structured content and metadata.

03 · INFER

Model reasoning

The configured local model receives the task and retrieved context for inference.

04 · INVOKE

Use a specialist capability

MCP exposes the required learning tool through an explicit contract and controlled boundary.

05 · PRACTISE

Turn explanation into action

The learner attempts an exercise, revision task, reading activity or assessment.

06 · ADAPT

Update learning state

Feedback and mastery signals can inform subsequent practice and progression.

MCP contract: capabilities are designed around explicit inputs, outputs, versioning, permission requirements, validation, safety constraints and evidence/provenance requirements. The aim is extensibility with control.
