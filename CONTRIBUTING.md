# Contributing to EnglishAI-Ecosystem

Thank you for helping build EnglishAI-Ecosystem.

There are two contribution paths.

## 1. Contribute directly to GitHub

No team membership is required. You can:

- report bugs or propose features through Issues;
- improve documentation;
- add or improve English-learning resources;
- develop Grammar, Vocabulary, Reading, Writing or Assessment capabilities;
- build MCP servers and tool integrations;
- improve RAG, knowledge engineering or local-model integration;
- contribute tests, evaluation methods, UX or deployment improvements;
- submit a pull request from your fork.

Start here: https://github.com/BurhanAbdullah/EnglishAI-Ecosystem

## 2. Apply to join the collaboration group

Group membership is different from an open-source contribution. It is intended for people who want to participate in an ongoing workstream with the project leads.

Use the website's **Join the Group** form and provide:

1. your name and email;
2. your preferred role;
3. the contribution stream you want to work in;
4. what you would like to contribute; and
5. your suggestions or ideas for EnglishAI.

The application is submitted as a GitHub issue for review. A project lead reviews the application. Approved applicants receive an email from the project team with the next collaboration steps.

## Contribution streams

- Engineering
- English Language and Pedagogy
- AI / RAG / MCP
- Research and Evaluation
- Documentation and UX
- Ideas and Partnerships

## Principles

Keep contributions learner-centred, evidence-aware, reproducible and respectful. Do not submit secrets, passwords, private keys, personal data that is not needed, copyrighted material without appropriate permission, or unsafe code.
